## Progetti in Evidenza
Nel portfolio troverai i seguenti lavori principali[cite: 3]:
* **Indice di robustezza delle banche europee:** Schema SQL, analisi di sensibilità in Python (SciPy) e dashboard Power BI su dati EBA 2024[cite: 3].
* **E-commerce Olist:** Modello a star schema con misure DAX e time intelligence in Power BI[cite: 3].
* **Analisi COVID-19:** Controllo qualità, gestione dei valori mancanti ed Exploratory Data Analysis (EDA) in Python (Pandas, Matplotlib)[cite: 3].
* **Festival di Sanremo (1951-2023):** Data engineering in Power Query e storytelling visivo su Looker Studio[cite: 3].
