## Progetti in Evidenza
Nel portfolio troverai i seguenti lavori principali:
* **Indice di robustezza delle banche europee:** Schema SQL, analisi di sensibilità in Python (SciPy) e dashboard Power BI su dati EBA 2024.
* **E-commerce Olist:** Modello a star schema con misure DAX e time intelligence in Power BI.
* **Analisi COVID-19:** Controllo qualità, gestione dei valori mancanti ed Exploratory Data Analysis (EDA) in Python (Pandas, Matplotlib).
* **Festival di Sanremo (1951-2023):** Data engineering in Power Query e storytelling visivo su Looker Studio.

Tutti i repository completi di dataset, script e note metodologiche sono accessibili direttamente dal mio [profilo GitHub](https://github.com/carol-bmr).
